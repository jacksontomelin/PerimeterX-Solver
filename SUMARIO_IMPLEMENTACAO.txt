📝 O QUE É drc|1402?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

O `drc|1402` é um código retornado pelo PerimeterX v6.7.9 indicando um
HUMAN CHALLENGE VISUAL. Isso significa que o servidor quer confirmação humana
através de um desafio interativo que REQUER UM NAVEGADOR REAL.

❌ Não pode ser resolvido com HTTP requests puros
✅ Requer navegador real com Playwright

Exemplos de desafios:
  1. Hold and Release (padrão) - Pressione e segure por X segundos
  2. Swipe - Arraste mouse de ponto A para ponto B
  3. Click - Clique em coordenada específica
  4. Rotate - Girar imagem até posição correta

PXSolver.solve()
    │
    ├─ request_1() → PerimeterX response
    │
    ├─ Verificar se tem "drc|1402"?
    │   │
    │   ├─ SIM → HumanChallengeSolver (Playwright)
    │   │         ├─ Abrir navegador Chromium
    │   │         ├─ Extrair challenge data do DOM
    │   │         ├─ Detectar tipo (hold/swipe/click)
    │   │         ├─ Executar gesto
    │   │         └─ Retornar _px3 token ✅
    │   │
    │   └─ NÃO → solve_request() (HTTP normal)
    │
    └─ Retornar _px3 token

Resultado: O solver agora resolve AUTOMATICAMENTE desafios visuais!


💻 COMO USAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ INSTALAÇÃO:

   pip install -r requirements.txt
   bash install-playwright.sh

2️⃣ USO AUTOMÁTICO (recomendado):

   from solve import PXSolver

   solver = PXSolver(
       app_id="PX0OZADU9K",
       ft=221,
       collector_uri="https://...",
       host="https://site.com",
       sid="...",
       vid="...",
       cts="..."
   )

   token = solver.solve()  # ✅ Detecta e resolve drc|1402 automaticamente!

3️⃣ USO DIRETO (controle fino):

   from human_challenge import solve_human_challenge_sync

   # Síncrono (mais simples)
   success, token = solve_human_challenge_sync(
       url="https://site.com/login",
       proxy=None,
       headless=True
   )

   # Assíncrono (melhor performance)
   import asyncio
   from human_challenge import solve_human_challenge

   async def resolver():
       success, token = await solve_human_challenge(
           url="https://site.com",
           proxy="proxy.com:8080"
       )

   asyncio.run(resolver())
